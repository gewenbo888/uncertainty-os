# Uncertainty OS · 不确定性操作系统

A working surface for thinking in probabilities, pricing tails, and choosing among decisions whose payoffs are not numbers but distributions.

## Links

- **Live:** [uncertainty-os.psyverse.fun](https://uncertainty-os.psyverse.fun)
- **Vercel:** [uncertainty-os.vercel.app](https://uncertainty-os.vercel.app)
- **GitHub:** [github.com/gewenbo888/uncertainty-os](https://github.com/gewenbo888/uncertainty-os)

## Modules

1. **Probability Space** — full distributions, not point estimates
2. **Scenario Generator** — 800-path Monte Carlo fan charts
3. **Risk Map** — probability × impact scatter with EV asymmetry
4. **Decision Under Uncertainty** — score = E[·] − λσ − κ·tail + ω·reversibility
5. **Black Swan Detector** — normal vs fat-tail survival curves
6. **Branching Futures** — decision tree with path probabilities

## Stack

Next.js 16 App Router · TypeScript · Tailwind CSS v4 · JetBrains Mono + Manrope + Spectral
